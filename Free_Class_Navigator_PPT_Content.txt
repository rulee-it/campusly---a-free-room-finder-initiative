SLIDE 2: INTRODUCTION
--------------------------
What is Free Class Navigator?
- Web application designed for Sharda University students
- Helps locate available classrooms quickly and efficiently
- Modern, Netflix-inspired dark theme interface
- Mobile-responsive design for access on any device
- Created to optimize campus resource utilization

--------------------------
SLIDE 3: THE PROBLEM
--------------------------
Challenges Students Face:
- Difficulty finding empty classrooms for study sessions
- Time wasted searching multiple buildings
- No centralized system to check room availability
- Conflict with scheduled classes
- Limited knowledge of available spaces across campus blocks

--------------------------
SLIDE 4: OUR SOLUTION
--------------------------
Free Class Navigator: Streamlined Classroom Discovery
- Instant search based on three simple criteria:
  - Block number
  - Day of the week
  - Time period
- Real-time availability information
- Filtering options by floor preference
- Sort results by room number or floor
- Responsive design for all devices

SLIDE 7: HOW IT WORKS
--------------------------
Search Process:
1. Select Block: Choose specific building block
2. Choose Day: Select day of the week
3. Pick Time: Select desired time period
4. View Results: Browse available classrooms
5. Apply Filters: Refine by floor preference
6. Sort Options: Organize by room number or floor
7. Get Details: See complete room information
